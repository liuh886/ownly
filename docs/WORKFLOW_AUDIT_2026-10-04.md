# Ownly 操作与业务流程审计（2026-10-04）

本次沿着用户操作追踪 UI、动作层、Markdown 仓库和云端状态的衔接，重点检查成功、失败、重试、切换目录、归档恢复和历史数据编辑。测试用于固定发现的行为；结论还来自代码逐段审查、真实 Markdown 序列化，以及构建产物上的 Chromium 操作。

检查与修复均在本地工作区进行，未执行线上 Supabase 写入、撤销或发布，未发布站点或写入用户真实数据目录。现有未提交修改保留。

## 已修复的流程缺陷

| 操作 | 原问题 | 修复后的行为 |
|---|---|---|
| 空目录首次引导 | 点击“设置第一条记录”仍停留在讲解步骤；示例载入中可关闭/切换 | 每次打开独立推进步骤；载入中锁定退出及重复提交 |
| 保存记录后刷新失败 | 磁盘已写入，却把刷新失败当保存失败，引导用户重复提交 | 明确提示已保存、读取失败可重试；新对象完成引导以写入结果为准 |
| 文件夹切换/断开 | 延迟 picker、自动恢复和分步写入可能覆盖较新的连接或跨目录 | 连接提交有版本保护；写入组绑定原句柄与数据根；旧回调不操作新目录 |
| 同名并发写入及编辑已删记录 | 文件名分配可能互相覆盖；update 可能重新创建消失的文件 | 仓库串行保护文件名分配与关联写入；编辑核验文件存在及身份；不静默重建 |
| 归档/恢复失败 | 删除源失败后清理副本，极端情况下可能丢失最后一份记录 | 先写副本；清理前验证源仍在，无法确认时保留副本并报告部分完成 |
| 切换对象类型 | ID、创建日期或币种变化；旧类型字段残留 | 保留身份、原币种、通用扩展字段；清除旧类型专属字段 |
| 对象表单 | 可选空值变成 0、非法日期/坐标可保存、原生金额 input 拒绝小数 | 空值与 0 区分；边界校验；允许小数；保存中阻止重复提交/Escape，失败保留输入 |
| 对象使用状态与日志 | 状态写入后日志失败，状态与历史不一致 | 相关步骤在一个绑定写入组中执行，失败补偿；补偿失败明确报告 |
| 复盘创建、编辑及归档恢复 | 新建/编辑目标混淆、重复复盘、对象反向引用或 reviewed 状态失配 | 明确提交目标、复用已有目标复盘、同步关联及状态，失败补偿；孤立引用恢复时修正 |
| 编辑历史账户快照 | 只改资产会清空可见预填负债；编辑旧快照重算当下持有指标 | 首次编辑物化两边预填值；保留历史持有指标、身份、正文及扩展元数据 |
| 同名多币账户历史编辑 | 只按账户名称复用第一行，另一币种的身份及元数据被覆盖 | 编辑文本标明币种，按名称及币种独立匹配每一原始账户；新行分配不冲突的身份，重排不改变已有身份 |
| 同日多份账户快照 | UI 取旧余额、差额方向反转；修改旧快照又可能改变“最新” | 按 snapshot_at、原始 created_at 和稳定身份排序；updated_at 不改变快照发生顺序 |
| 金额与币种 | 英文 UI 显示 USD 却写 CNY；换符号后把不同币种相加 | 新记录保存所选单位；历史记录按来源单位显示；首页/账户/对象金额只汇总同币种并说明范围，所有记录仍可浏览 |
| 演示与首次语言偏好 | 英文默认 USD 筛空 CNY 示例账户；中文首次渲染沿用服务端 USD 默认值 | 演示临时以 CNY 展示，演示内选择不改真实偏好；首次默认币种跟随实际检测到的语言，明确选择后保留偏好 |
| 0 金额、评分及只读详情 | 0 被当空值；非法评分静默转空；禁用状态连详情也无法打开 | 保留 0，拒绝非空非法评分并保留草稿；只读允许查看，禁用修改 |
| Planner 费用与汇率 | 未等待写入就关闭/更新状态，失败丢失输入 | 等待写入、锁定重复操作、失败保留草稿并可见提示 |
| 行程复盘写入后关联失败 | 重试重复建对象或覆盖已编辑正文；Markdown 规范化换行误报冲突 | 稳定 ID、实际持久化基线；重试更新本次草稿，外部修改冲突时保留用户输入 |
| 分享/日历自动更新 | 上传 A 期间编辑 B 被遗漏；延迟自动更新可重新启用已停用链接 | 记录实际上传快照并补传后续编辑；发布操作串行及失效保护；服务端 refresh 只条件更新仍启用且凭据匹配的记录 |
| 停用/旋转链接 | 服务端零行更新被当停用成功，旧链接可能仍可访问 | 要求实际更新确认；无法确认时提示失败，禁止继续旋转发布 |
| 复制行程到另一目录 | 全局凭据和相同 trip ID 可能复用/覆盖另一目录发布 | 凭据及远端日历身份按稳定目录 namespace 隔离；同名不同目录不共用 |
| 旧版本已发布链接管理 | 隔离凭据后可能失去旧链接停用入口 | 显式认领旧分享/日历凭据；限制跨目录重复认领；多个旧账号订阅可逐一停用；行程订阅提供停用入口 |
| Planner 撤销 | 目录切换后旧撤销闭包可能把记录恢复到新目录 | 绑定原写入会话并校验当前目录；失败提示而非只写控制台 |

## 实际边界

浏览器操作覆盖了原生文件句柄、Markdown 和 IndexedDB 的衔接，但没有操作 Windows 文件夹选择器或测试 OS 权限被撤销、移动真实目录后的恢复；这些仍需真机验证。云端撤销和跨客户端刷新通过请求合同测试验证，未实际停用线上链接。Web/PWA、Obsidian、扩展的构建与共享运行时检查不能替代所有设备的人工操作。

多币种汇总采用明确的同币种范围，没有引入汇率换算；旧记录缺币种时按既有 CNY 语义解释。浏览器关闭前云端成功但本地凭据保存失败的情况有明确恢复提示，仍受本地存储可用性影响。仓库补偿保护当前应用内的操作，不能将外部编辑器同时写文件变成跨应用事务。

此前报告中的开发工具链依赖迁移与 iPhone 分享查看验证仍未完成；本次没有扩大到这些独立事项。
